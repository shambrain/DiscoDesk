# Desktop UI design workflow

1. Read ARCHITECTURE.md Addendum A9 and docs/DESKTOP_EXPERIENCE_SPEC.md.
2. Build the primary flow first: active wallpaper, analysis/reaction state, audio source and pause.
3. Use neutral surfaces, clear typography, consistent spacing and a restrained accent.
4. Use Mica/Acrylic only where supported and appropriate; provide solid fallback.
5. Keep normal mode simple; place mapping curves, DSP and fine shader controls in Advanced.
6. Cover idle, analysing, reacting, paused, unsupported, permission denied, disconnected and recovering.
7. Include light/dark/system, high contrast, keyboard/focus, screen readers and reduced motion.
8. Never communicate critical status by motion or color alone.
9. Use FigCraft when connected and report actual artifacts built.
10. Review responsive layout, onboarding, empty/error states and long-session comfort.
